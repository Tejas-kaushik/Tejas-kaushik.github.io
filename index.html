  • Phones join a room by QR code; rooms sync live through Supabase with a big-screen spectator mode and podium.

Code Play it

A Redis-compatible server built from scratch on Linux system calls, no third-party libraries. The stock redis-cli and redis-benchmark work against it unmodified.

  • Single-threaded epoll event loop, zero-copy RESP2 parser, incrementally rehashed hash table, key expiry, and an append-only file that survives kill -9.
  • Matches Redis 8 throughput on GET, SET and INCR with 10,000 concurrent clients (persistence off).
  • 39 unit and 72 integration tests, parser fuzzing, a 3M-operation stress test, and CI under ASan, UBSan and valgrind.

An autonomous robot built from discrete components, not a kit, with dual-core FreeRTOS firmware and a live Wi-Fi tuning dashboard.

  • The PID loop runs as a hard-real-time task pinned to its own core, with mutex-guarded shared state, so Wi-Fi traffic cannot jitter it. Measured flat at 200 Hz under sustained network load.
  • An async WebSocket server on the ESP32 streams sensor, PID and motor metrics; gains change live, so a rebuild-and-reflash cycle became an instant update.
  • Measured and linearised motor dead-band, adaptive corner slowdown, sensor autocalibration persisted to flash.

Code

A voice assistant engineered around one latency budget: the first sound back within a second of you finishing your sentence.

  • Fully local voice loop: WebRTC VAD, faster-whisper speech to text, an LLM, then Piper text to speech, with every stage measured.
  • Tools served over the Model Context Protocol (weather, news, web search, system state), plus an async deep-analysis job so it keeps talking while it thinks.
  • 17 of 17 on its own evaluation harness.
